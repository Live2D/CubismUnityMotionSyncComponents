# Notices

## [Caution] Support for Apple's Privacy Manifest Policy

This product does not use the APIs or third-party products specified in Apple's privacy manifest policy.
This will be addressed in future updates if this product requires such support.
Please check the documentation published by Apple for details.

[Privacy updates for App Store submissions](https://developer.apple.com/news/?id=3d8a9yyh)

## [Notice] Model Display Issues When Importing Prefabs

The model may not render correctly if this product is imported into a render pipeline environment other than what is supported by the Cubism SDK for Unity, as specified in the README.
This issue will be addressed in future updates of the Cubism SDK for Unity.
As a temporary workaround, completely deleting the model from the project and then re-importing it may resolve the issue.
